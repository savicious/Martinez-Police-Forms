## Reporting a Bug

When submitting a bug report, please include:

- **Issue Description:** A clear explanation of the problem.
- **Steps to Reproduce:** What actions caused the issue?
- **Expected Behavior:** What should have happened?
- **Actual Behavior:** What happened instead?
- **App Version:** The version of Martinez Police Forms installed.
- **iOS Version:** Your device's operating system version.
- **Screenshots:** If helpful, attach screenshots with all sensitive information removed.

Providing these details helps us investigate and resolve issues more efficiently.

## Privacy and Sensitive Information

**Do not include confidential, personal, or law enforcement-sensitive information in GitHub Issues.**

GitHub Issues may be publicly accessible.

Never submit actual incident reports, case numbers, personal identifying information, electronic signatures, or confidential departmental documents.

When providing examples, use fictional or fully sanitized information.

## Application Privacy

Martinez Police Forms stores application information locally on the user's iPhone. The application does not use cloud storage, analytics, advertising, or external data-collection services.

For additional information, review our:

[Privacy Policy](https://github.com/savicious/Martinez-Police-Forms/blob/main/PRIVACY.md)
